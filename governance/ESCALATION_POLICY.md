# Politique d’escalade

## Escalade immédiate au Lead Developer

- Modification architecture.
- Suppression de code important.
- Dépendance nouvelle.
- Refactor multi-modules.
- Échec build non expliqué.
- Comportement non reproductible.

## Escalade immédiate au DevOps / AgentOps

- Secret exposé.
- Problème CI/CD.
- Permissions.
- Accès externe.
- Déploiement.
- Coût IA anormal.

## Escalade immédiate au Manager IA

- Dérive du scope.
- Tâche mal définie.
- Conflit priorité.
- Retard critique.
- Besoin métier ambigu.

## Escalade sécurité

Toute modification liée à :
- auth ;
- paiement ;
- données personnelles ;
- rôles utilisateurs ;
- webhooks ;
- stockage ;
- logs sensibles.
