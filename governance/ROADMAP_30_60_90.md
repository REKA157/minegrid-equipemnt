# Roadmap 30 / 60 / 90 jours

## Jours 1 à 30 — Pilote contrôlé

Objectifs :
- Installer le kit dans un dépôt.
- Définir les rôles humains.
- Créer les premiers tickets IA-ready.
- Limiter les agents aux tâches simples.
- Mesurer les premiers KPIs.

Livrables :
- AGENTS.md adapté.
- 10 tickets IA-ready.
- 5 PR agents.
- Dashboard KPI initial.
- Première rétrospective IA.

## Jours 31 à 60 — Industrialisation

Objectifs :
- Augmenter le nombre d’agents spécialisés.
- Ajouter tests automatiques.
- Créer templates de PR.
- Mettre en place une routine quotidienne.
- Formaliser les prompts.

Livrables :
- Agent Frontend.
- Agent Backend.
- Agent Test.
- Agent Reviewer.
- Agent Documentation.
- 20 à 30 PR agents suivies.
- Rapport d’efficacité.

## Jours 61 à 90 — Mise à l’échelle

Objectifs :
- Standardiser sur plusieurs projets.
- Automatiser les tâches répétitives.
- Créer une vraie cellule AgentOps.
- Mettre en place des evals IA.
- Identifier les tâches semi-autonomes.

Livrables :
- Playbook organisationnel.
- KPIs consolidés.
- Bibliothèque de prompts.
- Matrice de délégation validée.
- Politique d’accès agents.
- Plan de montée en charge.
