# KPIs de pilotage IA-native

## KPIs de production

- Nombre de tickets confiés aux agents.
- Nombre de PR générées par agents.
- Taux de PR acceptées.
- Taux de PR rejetées.
- Temps moyen ticket → PR.
- Temps moyen PR → merge.
- Temps moyen de revue humaine.

## KPIs de qualité

- Build success rate.
- Test pass rate.
- Bugs post-merge.
- Régressions UI.
- Dette technique créée.
- Nombre de rollbacks.

## KPIs économiques

- Coût IA par ticket.
- Temps humain économisé estimé.
- Temps humain passé en revue.
- Ratio gain net / coût IA.

## KPIs d’apprentissage

- Erreurs récurrentes agents.
- Prompts améliorés.
- Règles ajoutées dans AGENTS.md.
- Tests créés suite à erreurs.
- Tâches devenues automatisables.

## Lecture saine des KPIs

Un volume élevé de code généré n’est pas un succès en soi.  
Le vrai succès est :

```text
plus de fonctionnalités livrées
+ moins de bugs
+ moins de temps perdu
+ meilleure traçabilité
+ coût maîtrisé
```
