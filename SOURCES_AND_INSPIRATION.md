# Sources et inspiration

Ce kit est inspiré des pratiques publiques observables chez les organisations qui intègrent des agents IA au développement logiciel :

- OpenAI Codex : agent de développement logiciel, travail en sandbox, PR, tests, logs.
- Anthropic Claude Code : bonnes pratiques sur contexte, tests, agents, qualité.
- GitHub Copilot Coding Agent : assignation d’issues, branches, PR, GitHub Actions.
- Google : code généré par IA puis revu par ingénieurs, migration de code assistée par LLM.
- Pratiques générales DevOps, CI/CD, code review, security gates et evals IA.

Principe central :
l’IA augmente fortement la vitesse uniquement lorsque l’organisation possède des specs claires, des tests, des règles d’accès, des revues humaines et des métriques de qualité.
